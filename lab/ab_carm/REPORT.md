# C 档补跑：无先验（route=0）× MC 搜索（4096/rad1.4）四臂对照

日期：2026-11-03　分支：`lab/gates-variantC`　基座：ga-r2 冠军配置
种子：62700–62719（CRN 配对，n=20/臂 × 4 臂 = 80 局）

## 背景

§8.3 曾判「MC（引擎 FlatSearch，教诲落位择优）在 4096/rad1.4 口径下叠先验增益 +826」，
但 C 档（route=0 无先验 + 搜索）当时因二进制早于配置改动、`deny_unknown_fields` 拒键而 0/20 作废。
本轮补跑，回答 §8.8-2：「MC 单独（无蒸馏先验）是否也增益」。

## 设计

2×2 因子：先验（`[trainer.advice] route` = 500 / 0）× 搜索（`MATSURI_SEARCH_N=4096 TOPK=4 RADICAL=1.4` 开 / 关）。
其余全按 ga-r2 冠军配置。朋友槽 SSR 吾妻、无根卡、禁马照旧。

## 结论

1. **MC 单独（无蒸馏先验）也增益**：C1−C0 = +539.2，方向为正但不显著，且把方差/最差局拉大
   （min 62669→60814）——搜索在没有好先验引导时会在部分局面选到更激进的落位。
2. **价值大头在蒸馏先验**（route=500 本身 −2107 若去掉，t=−2.47 显著）；搜索是叠在先验之上的
   增量（+952，与 §8.3 一致），且只有先验+搜索组合能把 min 抬到 71088（其余臂 min ≤ 65770）。
3. 生产结论不变：**保留 route=500 先验 + 搜索**。§8.8-2 关闭。

注：A0 73096.1 与 §8.3 的 74167.9 相差约 −1071，因 §8.3 跑在 halve 口径修正合入 ga-r2 之前的
冠军档；本轮四臂内部对照不受影响。
